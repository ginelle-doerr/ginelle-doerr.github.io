# Ginelle Doerr's GIS Portfolio

Welcome to my GIS portfolio! This website showcases my work and interests in geographic information systems, spatial analysis, and geospatial technology.

## Featured Projects

- Metro Building Footprints — An ArcGIS StoryMap on filling in missing building use types in Metro's RLIS data.
- Heat Equity Map — Inequitable exposure to environmental hazards in Portland.
- Little Libraries — An interactive ArcGIS Experience Builder web map of free little libraries around Portland.
- BEECNs — An interactive web map and StoryMap on Cascadia Subduction Zone earthquake preparedness.
- Mountain Goats — A site suitability analysis for mountain goats on Mount Hood.
- Urbanization and Temperature — Change in Portland metro surface temperatures between 1992 and 2019.
- Crater Lake National Park — A visitor map of Crater Lake National Park.
- Western Monarchs — An infographic of Western Monarch distribution.

## Tools & Technologies

ArcGIS Pro · ArcGIS Online · Python
